# China Family Quest v11 — актуальное меню и локации

## Что поменялось
- Девять актуальных страниц в бургер-меню без старых дублирующих пунктов.
- Главная: «Наш Китай 🇨🇳».
- Маршруты A / B / H / S / N сохранены; 26 октября Disneyland забронирован.
- «Все локации» объединяет карту, карточки мест, список маршрутов, посещения и прогресс.
- Посещение места синхронизируется между карточкой и маршрутами.
- «Мои отели» принимают ссылку на карту; отели больше не добавляются как геометки.
- «Итоги отпуска» возвращены к простому дневнику: «Наш N-й день в Китае», место для фото, число открытий, процент списка, доли расходов. Отдельный PNG 1080×1920.
- Ничего загружать на сайт для фотографии дня не нужно: добавьте фото поверх заготовки в редакторе Instagram.

## Фото
В архиве 14 ранее подготовленных локальных иллюстраций из v9.4 для соответствующих именных мест. Это не документальные фотографии объектов из интернета. Для остальных локаций предусмотрены аккуратные заглушки. Не подменяйте их снимками чужих мест. При наличии разрешённых реальных фото их можно добавить в `/images/` и зарегистрировать в списке PHOTO_IDS; проверьте авторские права и укажите атрибуцию. Автоматическое скачивание фотоматериалов из интернета в данной среде недоступно.

## Публикация
1. Сначала экспортируйте JSON предыдущей версии через «Мои данные» — это резервная копия.
2. Разархивируйте ZIP и загрузите **содержимое** архива в корень репозитория GitHub Pages, заменяя одноименные файлы.
3. Проверьте версию v11 сверху, обновите PWA (при необходимости удалите старый офлайн-кеш).
4. Убедитесь, что сохранились отели, расходы, маршруты и отмеченные места.

## Ограничения
- Геоподложка карты через OpenStreetMap требует интернета; доступность в Китае не гарантирована. Ссылки открытия точки в AMap работают отдельно.
- Не выполнен браузерный end-to-end тест на настоящем iPhone; синтаксис JavaScript проверен.
- Новые места, для которых адреса не были подтверждены, показывают карточку с названием и поиском в AMap без выдуманного адреса.

# China Family Quest v12 · Neo Chinese

## Основные изменения
- Главная: погода и выбранный план объединены в одну карточку; открытка убрана.
- Календарь: убраны «Открыть библиотеку» и заметки.
- Маршруты: галочки посещения записываются без перерисовки всей страницы; кнопки назначения и карты в карточках убраны.
- Локации: кнопка «Открыть →», названия изображений управляются по `PHOTO_FILENAMES.txt`.
- Чек-листы: добавление и удаление своих пунктов; сохранение в прежнем localStorage.
- Отели, приложения, итоги: убраны верхние кнопки «Назад».
- Приложения и советы: телефоны 110 / 120 / 119 / 122; адрес и контакты Генконсульства РК в Шанхае.
- Итоги: пять чередующихся тем Neo Chinese, прогресс-колеса и инфографика расходов, загрузка фото из галереи, экспорт PNG 1080 × 1920. Фото живёт в памяти вкладки до её закрытия; загрузи его перед экспортом.

## Обновление GitHub Pages
1. На работающем старом сайте экспортируй JSON с расходами и отметками, если доступен экспорт.
2. Загрузить **содержимое** ZIP (не сам ZIP) в корень репозитория, заменив старые файлы.
3. Обновить страницу/PWA (при необходимости удалить старый PWA с домашнего экрана и открыть заново).
4. Не очищать данные браузера: ключ хранения оставлен прежним, `china-family-quest-2026-v1`.
5. Дополнительные JPG положить в каталог `images/` с именами из `PHOTO_FILENAMES.txt`.

## Проверки
JavaScript проверен `node --check`. Реальное ручное тестирование в iPhone Safari отсутствует; перед вылетом проверь чекбоксы, экспорт открытки, офлайн-фотографии и восстановление JSON.

## Ограничения
- Интерактивная карта и новые JPG требуют сетевой доступ при первой загрузке.
- Экспорт открытки в PNG после выбора фотографии выполняется локально в браузере.
- Встроенные 14 WebP — стилизованные иллюстрации из предыдущей версии, а не документальные фото мест.

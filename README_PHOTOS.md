# China Family Quest — изображения v9.4

В `images/` находятся 14 файлов `*.webp` со всеми местами маршрута. Они являются сгенерированными в стиле Travel Editorial иллюстрациями, а не реальными документальными фотографиями конкретных мест.

## Публикация

Загрузите всё содержимое ZIP в корень GitHub Pages (с сохранением путей `images/`). Не загружайте сам ZIP как один файл. После публикации откройте сайт с интернетом: Service Worker автоматически сохраняет 14 изображений в кэш для офлайн-доступа. Для проверки включите авиарежим и откройте карточки мест.

## Замена реальными фотографиями

Замените любой файл в `images/`, не меняя имени. После замены нужно обновить идентификатор кэша изображений в `sw.js` и `index.html`, чтобы iPhone не показывал старую версию. Не запускайте прежний `Download location photos` workflow: он более не нужен.

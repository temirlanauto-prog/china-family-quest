China Family Quest v9.3 — Auto Offline Photos

1. Загрузите файлы из этого ZIP в корень репозитория (не удаляйте существующие .webp в images).
2. Для удаления старой автоматизации удалите из репозитория .github/workflows/photos.yml и scripts/download_photos.py.
3. Дополняйте /images реальными файлами jing.webp, kerry.webp, ... строго по images/manifest.json.
4. При запуске PWA с интернетом приложение автоматически скачает доступные изображения и положит в Cache Storage; отдельно нажимать «Загрузить» не нужно.
5. Изображения, отсутствующие на GitHub Pages (404), не могут загрузиться; их требуется один раз добавить в репозиторий.
6. Проверяйте фотографии, предварительно открыв сайт онлайн, затем в авиарежиме. iOS может очищать кэш при нехватке места.

Этот ZIP содержит САЙТ И ЛОГИКУ автокэша, но НЕ содержит фотографии: исходные снимки недоступны для загрузки в текущей среде.

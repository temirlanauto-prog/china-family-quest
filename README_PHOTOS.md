# China Family Quest v9.2 — Photo Setup

Это сборка с 14 привязками фотографий и обновлённым кэшем, но **без встроенных WEBP файлов**: в этой среде доступ к Wikimedia Commons для скачивания изображений заблокирован.

Для получения реальных файлов:
1. Загрузите содержимое ZIP в GitHub (сохранив существующие webp в images/).
2. В GitHub Actions запустите «Download location photos».
3. Убедитесь, что файл images/lv.webp и остальные 13 WebP появились в репозитории.
4. Дождитесь публикации GitHub Pages, откройте PWA в интернете и запустите «Фото офлайн».

ZZER и TX Huaihai имеют изображения окрестностей, НЕ самих заведений. Это намеренная маркированная замена; точных лицензированных фотографий объектов пока нет.

При повторном запуске скрипт не перезаписывает уже имеющиеся .webp.

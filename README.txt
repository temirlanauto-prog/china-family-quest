China Family Quest v7.0 — Offline Photos

1) Загрузите содержимое ZIP (включая .github/workflows/photos.yml, scripts/, images/) в корень GitHub репозитория.
2) GitHub Actions → Download location photos → Run workflow (если не запустилось автоматически).
3) Дождитесь зелёной галочки и появления файлов images/*.webp в репозитории. В настройках GitHub Actions / General / Workflow permissions может потребоваться Read and write permissions.
4) После появления картинок обновите сайт GitHub Pages и откройте установленное PWA при наличии интернета. Во вкладке «Мои данные» нажмите «Фото офлайн» и дождитесь 11/11.
5) Проверьте работу в авиарежиме. Если PWA ещё использует старый Service Worker, перезапустите приложение онлайн.

Используются 11 реальных фотографий с Wikimedia Commons; для lv, zzer, huaihai пока нет надёжно подобранных лицензированных фото — останутся корректные заглушки.
Фото принадлежат их авторам, подробности и лицензии: images/ATTRIBUTION.md (заполняется при загрузке).
На GitHub Pages данные пользователей не загружаются — они остаются в localStorage PWA. Перед обновлением экспортируйте JSON.

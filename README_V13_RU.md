# China Family Quest v13 — Minimal Chinese Daily Story

## Что изменилось

1. **Главная:** одна компактная карточка «Погода и план» без вложенной карточки погоды, дублирования даты и списка маршрутов.
2. **Маршруты / Маршрут по дням:** новые независимые обработчики чекбоксов `data-v13-visit` вместо старых `data-qvisitkey`, которым предыдущий обработчик отменял стандартное переключение. Отметки сохраняются в `state.visited` (ключ данных прежний), синхронизируются с другими маршрутами и обновляют счётчики без перерисовки фотографий.
3. **Строки маршрута:** у последней точки нет разделительной линии.
4. **Карточка локации:** кнопка называется «🧭 Построить маршрут ↗».
5. **Чек-листы:** добавление, удаление, отметка выполнения, пересчёт прогресса, сохранение состояния. Старые данные списков совместимы с v12 и v11.
6. **Приложения и советы:** интерактивные номера служб КНР и Генконсульства Казахстана в Шанхае; ссылки на звонок, почту, AMap и официальные сайты.
7. **Итоги отпуска:** новый светлый минималистичный Chinese editorial poster; огромное фото с мягким «перетеканием» краёв в бумажный фон (фон также создаётся из того же фото), круг дня из 15, две красные печати «Открытия» и «Must-see», строка посещений (X / Y). Расходы не показываются. Предпросмотр — настоящий Canvas, экспорт **того же** canvas в PNG 1080×1920.
8. На экране итогов поле даты адаптировано для узких iPhone, без горизонтального выхода за рамку.

## Пользовательское фото

Открой **Итоги отпуска → Выбрать фото**. Фотография выбирается с телефона, не отправляется на сервер. Ползунок «Положение фото» смещает центральный кадр вверх/вниз, «Масштаб фото» увеличивает изображение. Затем нажми **Сохранить постер**.

Фотография остаётся в памяти текущей открытой вкладки: после перезапуска сайта нужно выбрать её снова. Это сделано для экономии памяти телефона и сохранения приватности. Финальный PNG сохраняется в «Файлы»/«Загрузки» на устройстве.

## Как обновить GitHub Pages

1. Сначала в текущей версии экспортируй резервный **JSON** (через меню «Мои данные», если он доступен; либо из текущего сайта).
2. Распакуй ZIP. Загрузите **содержимое папки архива** в корень репозитория `china-family-quest` в GitHub, заменив одноимённые файлы.
3. Подожди обновления Pages. Для установленной PWA: выгрузи её и перезапусти, затем обнови версию/кэш. В шапке должна быть метка `v13`.
4. Проверь галочки в «Все маршруты», редактирование чек-листа, меню «Приложения и советы», экспорт открытки с собственной фотографией.

Данные расходов и маршрутов из предыдущей версии остаются в localStorage; имя ключа **не менялось**.

## Фото локаций

Добавляй JPG в `images/` в точном соответствии с `PHOTO_FILENAMES.txt`. Если файл JPG отсутствует, для ряда ранее подготовленных мест доступен резервный WebP. Изображения локаций не создаются заново и не перезаписываются обновлением данных маршрутов.

## Проверка

- Проверена синтаксическая корректность JavaScript (`node --check`).
- Автоматизированный тест браузера: чекбокс маршрута → сохранение → повторный рендер, чек-лист добавить/отметить/сохранить/удалить, ширина даты, экспорт PNG с фото.
- Проверка на реальном iPhone Safari и доступность карт OSM/AMap в Китае **не проводились**.

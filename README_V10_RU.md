# China Family Quest v10 — гибкие маршруты

## Установка на GitHub Pages
1. **Перед обновлением** в старой версии сайта откройте «Ещё → Мои данные → Сохранить JSON». Сохраните копию отдельно.
2. В репозитории `china-family-quest` обновите **всё содержимое ZIP** с сохранением путей: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-*.png`, папку `/images`. Удалять существующие фотографии не требуется, если они совпадают с архивом.
3. После публикации откройте сайт Safari, при необходимости нажмите «Проверить обновление» в меню и перезапустите PWA. Откройте новое приложение и убедитесь, что расходы и отели на месте.

## Что нового
- Даты с независимым выбором **дневного**, **вечернего** и **solo day** маршрута.
- Каталог A01–A08, B01–B04, H01–H02, S01–S04, N01–N05. H02 переименован из второго H01, чтобы избежать конфликта кодов.
- Билет в Disneyland **26 октября** закреплён и не заменяется в календаре. Билеты в Ханчжоу НЕ считаются купленными.
- Чек-листы маршрутов с отдельным выбором ★ обязательно или ☆ по желанию. Прогресс посещений сохраняется локально.
- Интерактивная карта с панорамированием и масштабированием на касании, общий слой по городам; внутри дня только точки привязанных маршрутов. Названия кликабельны, открывается AMap.
- Отели: можно ввести координаты вручную из AMap на общей карте. Пока они не заданы, точки отелей на карте отсутствуют.
- Новые «Итоги Китая»: открытка дня с фото, прогрессом must-see и bonus, процентной разбивкой расходов без сумм и экспортом 1080×1920 PNG офлайн.

## Ограничения
- Для самой подложки карты нужен интернет и доступность `tile.openstreetmap.org` (в Китае он может быть ограничен); интерфейс жестов и список ссылок AMap работают независимо от подложки. **Нативную карту AMap JS** без собственного API-ключа и безопасной настройки нельзя гарантированно встроить на GitHub Pages. Для маршрута и навигации используйте кнопки AMap.
- Координаты части новых мест приблизительны, это метки района, **не подтверждённые входы**. Откройте место в AMap, чтобы проверить точное расположение.
- SPA-конкретный комплекс ещё не выбран, поэтому не отображается точкой.
- Фотография дня сжимается и хранится в хранилище браузера, а не в GitHub.
- Данные хранятся **на устройстве**, автоматически НЕ синхронизируются между iPhone/Mac. Переносите их JSON-экспортом и импортом.
- Карта и фотографии на сайте — ориентиры. Открытые ссылки в AMap требуют соединения с интернетом.
